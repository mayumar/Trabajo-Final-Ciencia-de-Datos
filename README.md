# Trabajo Final Ciencia de Datos

Proyecto de **Ciencia de Datos y Aprendizaje Automático** orientado a la predicción del abandono de clientes bancarios mediante técnicas de *machine learning*.

## Contenido

* Análisis exploratorio y preprocesado de datos
* Ingeniería y selección de características
* Comparación de múltiples modelos de clasificación
* Optimización de hiperparámetros con Optuna
* Evaluación mediante validación cruzada y Kaggle

## Dataset

Competición de Kaggle: *Retención de clientes de una entidad financiera*.

## Modelo final

El modelo seleccionado fue **Random Forest**, priorizando estabilidad y capacidad de generalización en la evaluación externa.

## Reproducibilidad

El código incluye pipelines completos para evitar *data leakage* y garantizar resultados reproducibles.
